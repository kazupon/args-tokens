# Interface: BaseOptions

> [!WARNING]
> This API is experimental and may change in future versions.

Common options shared by all base combinators.

```ts
export interface BaseOptions
```

| `required` _(optional)_    | `boolean` | Mark as required. A literal `true` or `false` is kept in the type of the schema: `true` types the value as present, as [required](/docs/combinators/functions/required.md) does, and `false` makes a positional argument optional. So does a `required` that may be `false`: one of type `boolean`, or a `false` that the options have only in some cases, such as `optional ? { required: false } : {}`. A `true` that the options have only in some cases, such as `strict ? { required: true } : {}`, is not kept. Options whose type only says that `required` is a `boolean` that may be missing, as this one does, keep a positional argument typed as present, as options without `required` do. So do the options that a generic helper passes on, since their type is its type parameter. Use [unrequired](/docs/combinators/functions/unrequired.md) for a positional argument that may be missing then. |
| `short` _(optional)_       | `string`  | Single character short alias.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
