# Interface: ResolveArgs

An arguments for [resolve arguments](/docs/default/functions/resolveArgs.md).

## Signature

```ts
export interface ResolveArgs
```

## Properties

| Name                          | Type      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `passthrough` _(optional)_    | `boolean` | Whether to give the arguments that the schema does not take, such as for a CLI that passes them on to another program. When `true`, `passthroughIndices` of the result has the indexes, in the arguments given to `parseArgs()`, of the arguments that the schema does not take, in ascending order. They are an option that is not in the schema, with the argument that it takes as its value, which is the next argument unless that argument is an option, as without `passthrough`. A short option group with an option that is not in the schema is given whole, as it was given, such as `-qk` with `q` in the schema, whose options in the schema are still resolved. Without `shortGrouping`, a group is its first option, with the other letters as its value, so it is given only when that option is not in the schema. A positional argument that no positional argument of the schema takes, after the ones up to `skipPositional`, and the arguments after `--`, but not `--` itself, are given too. An option of the schema, the argument that it takes as its value, and a positional argument that the schema takes are not given. The indexes are given even when there are validation errors, as `values` are. `parse()` also gives the arguments at the indexes, as `passthrough`. When `false`, the indexes are not collected, and `passthroughIndices` is an empty array. **Default:** `false` |
| `shortGrouping` _(optional)_  | `boolean` | Whether to group short arguments. When `true`, each letter of a short option group is an option, and a value goes to the last one: `-vp 5` is `-v` and `-p` with `5`. When `false`, the other letters of a group are the value of its first option, which then does not take the next argument: `-p5 file` is `-p` with `5` and the positional `file`, and `-nfoo=bar` is `-n` with `foo=bar`. A boolean first option ignores the other letters, so `-vs` is only `-v`. **Default:** `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `skipPositional` _(optional)_ | `number`  | Skip positional arguments index. **Default:** `-1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `toKebab` _(optional)_        | `boolean` | Whether to convert the argument name to kebab-case. This option is applied to all arguments as `toKebab: true`, if set to `true`. **Default:** `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
